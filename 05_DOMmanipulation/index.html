//innerText : innerText is used to set or return the text content of the specified node, and all its descendants.(which is visible to the user) It will not return the text of hidden elements. It is aware of styling and will not return the text of hidden elements. It will return the text as it appears on the page, including line breaks and spacing. //TextContent : textContent is used to set or return the text content of the specified node, and all its descendants. It will return the text of hidden elements. It is not aware of styling and will return the text as it appears in the HTML source code, including line breaks and spacing. //innerHTML : innerHTML is used to set or return the HTML content of an element. It can be used to get or set the HTML markup inside an element, including any child elements and their attributes. It allows you to manipulate the structure and content of an element dynamically.
